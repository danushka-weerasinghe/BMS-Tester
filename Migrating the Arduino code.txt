•	BMS_IC is defined in LTC68xx_API.c
•	TOTAL_IC is defined in flash_Itc.h file 
•	ADC Command Configurations are defined in LTC68xx_API.c
•	Under Voltage and Over Voltage Thresholds are in LTC68xx_API.c
•	Configuration variables are defined in LTC68xx_API.c
•	STM32 print function declarations used instead of Serial.print/Serial.println etc. functions are defined in main.c
•	Delay function used is defined in LTC68xx_API.c
•	CRC table is defined in the LTC681x.c source file not in the header file.

•	In LTC681x.c file,
data[data_counter++] + (data[data_counter++]<<8);  -> data[data_counter] + (data[data_counter+1]<<8);

The order of evaluation of the two ++ operations is not guaranteed in data[data_counter++] + (data[data_counter++]<<8); therefore, it is replaced as above.
